# Contributing

Open an issue with your Omarchy version, affected plugin ID, steps to reproduce and any visible error. Remove personal information from logs and screenshots before posting.

For changes, preserve existing bar settings, verify selection and deselection, and check that clicking the gear opens the chooser while selecting a tile opens the native panel. Include your validation results in the pull request.

Runtime wrappers, icon caches, preferences and backups should not be committed. Contributions are provided under the repository’s MIT license.
