# Changelog

## 1.0.1

- Use Omarchy’s keyboard-enabled panel so the plugin search receives typed input.
- Focus the search field when the selection editor opens.
- Match plugin IDs as well as names and descriptions, ignoring surrounding spaces.
- Support Escape to close the chooser.

## 1.0.0

- Configurable Quick Settings chooser for compatible installed plugins.
- Native panel routing and hidden bar hosts with preserved settings.
- Searchable selection editor, three-column tiles and overflow scrolling.
- Native icon rendering, custom artwork and periodic status refresh.
- Concealed, non-interactive hidden bar buttons to prevent click collisions.
